# Contributing to AeroGuard

Thank you for your interest in contributing! Please note that AeroGuard is **proprietary software** owned by Fifko_Hraje. External contributions are not currently accepted.

## How You Can Help

- **Report issues** — Open a GitHub Issue describing bugs, feature requests, or improvements.
- **Suggest features** — Use the GitHub Discussions or open a feature request issue.
- **Translate docs** — Help translate the README or documentation into other languages.

## Submission Guidelines

1. **Search existing issues** — Before opening a new issue, check if it's already been reported.
2. **Provide details** — Include OS version, AeroGuard version, steps to reproduce, and screenshots when applicable.
3. **Respect the license** — All contributions remain the property of Fifko_Hraje. By submitting ideas or feedback, you acknowledge they become proprietary to AeroGuard.

## Q&A

- Check the [Issues](https://github.com/fifkohraje/AeroGuard/issues) tab.
- Visit the [README](https://github.com/fifkohraje/AeroGuard#readme) for setup help.
