# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.10.7-A | :white_check_mark: Yes |
| < 1.10.7 | :x: No             |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue. Instead:

1. Email the maintainers directly.
2. Include as much detail as possible:
   - Description of the vulnerability
   - Steps to reproduce
   - Impact assessment
   - Suggested fix (if any)
3. We will acknowledge receipt within 72 hours and coordinate disclosure.

## Scope

We consider vulnerabilities in the AeroGuard engine, UI, and bundled scripts. We do not consider:
- Third-party library vulnerabilities (report to the respective maintainers)
- Issues in user-configured environments
- Social engineering or phishing attempts

## Disclosure Policy

We follow a responsible disclosure process. You will be notified of progress and given a reasonable window to coordinate public disclosure before details are published.

## Contact

For security issues only — please use the email address associated with the repository owner.
